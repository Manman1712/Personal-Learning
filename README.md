# Personal Learning · 个人能力提升学习库

teach 技能产出的教学内容、知识漫画、小红书/公众号发布文案，统一归档在此仓库。

> 公开仓库 · 任何人可见、可搜索、可抓取

## 上传前必读：脱敏红线

本仓库为**公开**仓库。上传任何内容前必须逐项确认：

- [ ] 不含公司真实名称、员工姓名、工资表/花名册/银行卡等敏感信息
- [ ] HR 与用工合规案例已改写为通用场景，隐去可识别的主体
- [ ] 不含孩子的姓名、学校、照片等个人信息
- [ ] 不含未公开的内部制度原文或草稿

## 目录结构

| 目录 | 用途 |
|------|------|
| `lessons/` | teach 生成的课程 HTML |
| `comics/` | 知识漫画（PNG / PDF） |
| `publish/` | 小红书 / 公众号发布文案（md / docx） |
| `notes/` | 可公开的学习笔记 |

## 归档流程

本地生成 → 脱敏检查 → 上传本仓库 → 确认后可删除本地副本。
